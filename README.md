# The Federal Benefits Gap - Book Landing Page

A single-page 11ty site for "The Federal Benefits Gap" by Michael Stevens.

## About the Book

**Title:** The Federal Benefits Gap  
**Subtitle:** The Definitive Guide to Your Federal Employee Retirement  
**Edition:** 2026 Edition  
**Author:** Michael Stevens  
**Publisher:** Capital Wealth Media  

## Development

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## Deployment

This site is deployed to Vercel automatically on push to main branch.

## Features

- Responsive design
- Dark navy/gold color scheme
- Scroll animations
- FAQ accordion
- Email capture form
- Mobile-optimized

## Technology

- 11ty (Static Site Generator)
- Vanilla CSS with CSS Custom Properties
- Vanilla JavaScript
- Nunjucks templating
